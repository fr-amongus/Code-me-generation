---
name: Code Me account scope
description: Product decision about account registration and password recovery for Code Me.
---

Code Me accounts use a username and password only. Do not ask for an email address or offer password recovery in this version. Keep Replit sign-in as a separate optional method.

**Why:** the user chose a simple initial signup flow and deferred email or another recovery method.

**How to apply:** preserve this scope in account forms, documentation, and future auth work unless the user changes the decision.
