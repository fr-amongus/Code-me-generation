---
name: Code Me Auto-code scope
description: Product boundary for the platform's self-improvement feature.
---

Auto-code in Code Me Generation targets the Code Me Generation platform itself. It must never modify user-generated projects.

**Why:** the user explicitly clarified that Auto-code is for improving Code Me Generation, not the projects users create with it.

**How to apply:** keep Auto-code proposals, previews, and approvals scoped to the platform source and separate from user project data.
